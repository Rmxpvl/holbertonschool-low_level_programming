# Analyse Dynamique (Dynamic Analysis)

## 📚 Objectifs d'Apprentissage

- Utiliser GDB pour déboguer un programme C pas à pas
- Configurer GDB dans VS Code pour un débogage visuel
- Comprendre les commandes fondamentales de GDB
- Analyser le comportement d'un programme à l'exécution

## 📂 Fichiers

| Fichier | Description |
|---------|-------------|
| `source.c` | Programme C source à analyser |
| `gdb_fundamentals.txt` | Guide des commandes GDB fondamentales |
| `gdb_vsc.txt` | Configuration de GDB dans VS Code |
| `prog` | Exécutable compilé pour le débogage |
