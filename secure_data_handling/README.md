# Gestion Sécurisée des Données (Secure Data Handling)

## 📚 Objectifs d'Apprentissage

- Comprendre les bonnes pratiques de gestion sécurisée des données en C
- Implémenter un système de stockage sécurisé avec gestion de sessions
- Gérer les ressources publiques et privées correctement

## 📂 Fichiers

| Fichier | Description |
|---------|-------------|
| `Makefile` | Compilation du projet |
| `main.c` | Point d'entrée du programme |
| `session.h` / `session.c` | Gestion des sessions utilisateur |
| `store.h` / `store.c` | Système de stockage sécurisé |
| `public_resources/` | Ressources accessibles publiquement |
| `secure_store/` | Données stockées de manière sécurisée |

## 🔧 Compilation

```bash
make
```
