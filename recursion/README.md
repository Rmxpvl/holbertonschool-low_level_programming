# Récursivité (Recursion)

## 📚 Objectifs d'Apprentissage

- Comprendre le concept de récursivité et les cas de base
- Implémenter des fonctions récursives classiques
- Différencier récursivité et itération
- Identifier quand utiliser la récursivité

## 📂 Fichiers

| Fichier | Description |
|---------|-------------|
| `main.h` | Header avec les prototypes des fonctions |
| `0-puts_recursion.c` | Affiche une chaîne suivie d'un retour à la ligne |
| `1-print_rev_recursion.c` | Affiche une chaîne en ordre inverse |
| `2-strlen_recursion.c` | Retourne la longueur d'une chaîne |
| `3-factorial.c` | Calcule la factorielle d'un nombre |
| `4-pow_recursion.c` | Calcule la puissance d'un nombre |
| `5-sqrt_recursion.c` | Calcule la racine carrée naturelle |
| `6-is_prime_number.c` | Vérifie si un nombre est premier |

## 🔧 Compilation

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o recursion
```
